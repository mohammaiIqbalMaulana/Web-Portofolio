## Introduction

Welcome to the Portfolio Web Application! This platform showcases the projects, skills, and contact information of Mohammad Iqbal Maulana. This manual will guide you through the features and usage of the website.

## Accessing the Portfolio

- Open your preferred web browser (Chrome, Firefox, Safari, Edge).
- Navigate to the portfolio URL: `https://yourportfolio.com` (replace with actual URL).
- The website is responsive and accessible on desktop, tablet, and mobile devices.

## Navigating the Website

### Main Sections

- **Home (Hero Section)**: Introduction and welcome message.
- **About**: Background information and biography.
- **Skills**: Technical skills and proficiencies.
- **Projects**: Portfolio projects with descriptions and links.
- **Contact**: Contact form to send messages.

### Navigation Menu

- Located at the top of the page.
- Use the menu links to jump to different sections.
- On mobile devices, use the hamburger menu to expand navigation.

### Language Selection

- Toggle between English and Indonesian using the language switcher in the header.

### Dark Mode

- Toggle between light and dark themes using the theme switcher in the header.

## Using the Projects Section

- Browse through the list of projects.
- Use filters (if available) to narrow down projects by technology or category.
- Click on a project card to view detailed information, images, and links.
- Access live demos or source code via provided links.

## Contacting the Owner

- Navigate to the Contact section.
- Fill in your name, email address, and message.
- Click the "Send" button to submit your message.
- You will receive a confirmation message upon successful submission.
- For urgent inquiries, use the provided social media links.

## Using the Admin Panel

### Access

- Admin panel is accessible at `https://yourportfolio.com/admin` (replace with actual URL).
- Requires login with admin credentials.

### Features

- Manage projects: create, update, delete.
- Upload project images and files.
- View contact form submissions (if implemented).
- Manage site content and settings.

### Security

- Keep your admin credentials confidential.
- Log out after each session.

## Troubleshooting

- If pages do not load, check your internet connection.
- Clear browser cache if you experience display issues.
- Contact the site owner if you encounter errors or broken links.
